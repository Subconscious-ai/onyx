# Financial model chat tests

The Models workspace uses one native Onyx conversation. The authorized
`inspect_model` MCP slot exposes the financial tools only when a complete Models
page is bound to the current actor. The existing `prepare_model_change` slot
retains its persona permission. Library authorization remains unchanged.

Models owns the calculator, JSON schemas, candidate validation, Apply and Undo.
`model_tool_contract.json` is generated by the Models repository with
`pnpm generate:onyx:tools`. Copy the generated file and update its semantic digest
in `model_page.py` together. `pnpm test:onyx:tools` detects schema drift in Models.

Onyx reads use the configured `MODEL_AGENT_TOOL_URL` and server-only
`MODEL_AGENT_TOOL_TOKEN`. The existing Models `/api/model-agent/tool` endpoint
must use the same token. A missing service fails closed. No substitute model or
calculator runs in Onyx. Financial writes remain proposals until the Models
browser validates the complete candidate and the user selects Apply.

Run the Onyx suite from this repository:

```sh
PYTHONPATH=backend python -m pytest --noconftest -q \
  backend/tests/unit/onyx/server/test_models_page.py \
  backend/tests/unit/onyx/server/query_and_chat/test_model_tools.py
```

The `Models chat tools` workflow runs this suite on hosted runners without
application credentials. The suite covers every financial action, sensitivity
on/off, charts, read routing, invalid arguments, drafts, capture identity and
failure behavior. Onyx MCP integration tests also cover actor-bound tool access. Run the runtime
and persisted tool-history regressions in the configured Onyx environment:

```sh
PYTHONPATH=backend python -m pytest -q \
  backend/tests/unit/onyx/tools/test_causl_tools.py \
  backend/tests/unit/onyx/chat/test_chat_utils.py \
  backend/tests/unit/onyx/server/test_models_page.py \
  backend/tests/unit/onyx/server/query_and_chat/test_model_tools.py
```

The companion Models suite runs the actual Squiggle engine:

```sh
pnpm test:onyx:tools
NEXT_PUBLIC_ONYX_ORIGIN=https://onyx.example pnpm test:e2e:onyx
```

The browser suite creates a model, edits formulas, adds/deletes cells, changes
cell types, creates/activates/deletes scenarios, opens/closes sensitivity and
renders a Squiggle histogram. The suite checks that proposals do not change the
grid before Apply, and that Undo restores the complete document. Browser transport
is controlled; these tests do not claim live inference or staff authorization.

Live native proof must use an authorized account, the real Onyx composer and
subscription-backed agent runtime. Verify the requested tool result, visible
grid change after Apply, complete restoration after Undo and fresh capture after
each model change. Keep financial snapshots and browser credentials private.

Hosted chat accepts the native ChatGPT provider or the native Anthropic provider
with a Claude subscription OAuth credential. Configure credentials through the
existing provider administration path. Obtain credentials from Doppler `beca`.
Restrict the provider to the existing authorized workspace persona. Do not change
the global model default or user permissions for a preview.

Hosted Claude requests use `https://api.anthropic.com` explicitly. Paid API keys,
gateway URLs, custom configuration and passthrough model overrides fail closed.
The existing LiteLLM adapter owns OAuth headers and native tool calling.

Run the subscription guard regressions with:

```sh
PYTHONPATH=backend python -m pytest -q \
  backend/tests/unit/onyx/llm/test_factory.py
```
